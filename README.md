
# Laravel-PHP-TodolistApp Software

 ## Overview
The Laravel-PHP-TodolistApp software is a simple CRUD application impletemted with tools like PHP, MySQL, Laravel, HTML, CSS, Bootstrap

## What the Document app does

- User can create a todo task
- User can read all todo tasks
- User can read a todo task
- User can update a todo task
- User can delete a todo task



## Technologies Used

This application is implemented with:

### Back-end Technologies:

- PHP
- MySQL
- Laravel


### Front-end Technologies:

- HTML
- CSS
- Bootstrap
